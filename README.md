# Moon textures for Moonface (TRMNL plugin)

Static textures read by the Moonface plugin:

- `relief-{1k,2k}.webp`: local relief (elevation minus its smooth trend, +-2.5 km mapped to 0..255)
- `albedo-{1k,2k}.webp`: how bright the surface is

Built with `dev/maketex.py` in the plugin repository from NASA's CGI Moon Kit (SVS 4720, https://svs.gsfc.nasa.gov/4720/): LRO LOLA elevation and LROC WAC colour mosaic. Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio, Arizona State University, LRO LOLA and LROC teams. Public domain.
